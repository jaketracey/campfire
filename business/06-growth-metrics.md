# Growth Metrics & KPIs

## North Star Metric

### **Weekly Active Conversations**

*Definition: Number of users who have at least one conversation session in a 7-day period*

**Why this metric:**
1. **Reflects core value** - Users who converse are experiencing the product
2. **Leading indicator** - Predicts retention and monetization
3. **Actionable** - Teams can directly influence it
4. **Not gameable** - Hard to artificially inflate meaningfully

### North Star Targets

| Timeline | Target | Rationale |
|----------|--------|-----------|
| Month 3 | 2,000 | Post-launch baseline |
| Month 6 | 10,000 | Growth validation |
| Month 12 | 50,000 | Scale proof |
| Year 2 | 200,000 | Market position |

## Growth Loops

### Loop 1: Organic Content Loop

```
User creates companion
        ↓
User has memorable conversation
        ↓
User shares on social (TikTok, Twitter)
        ↓
Content reaches new potential users
        ↓
New users sign up
        ↓
[Loop repeats]
```

**Key Metrics:**
| Metric | Target |
|--------|--------|
| Share rate | >5% of users |
| Views per share | >500 avg |
| Click-through rate | >2% |
| Signup conversion | >20% |
| **Loop Velocity** | ~0.2 new users per user |

### Loop 2: Referral Loop

```
User loves product
        ↓
User invites friends (referral link)
        ↓
Friend signs up (both get rewards)
        ↓
Friend creates companion
        ↓
Friend invites their friends
        ↓
[Loop repeats]
```

**Key Metrics:**
| Metric | Target |
|--------|--------|
| Referral rate | >10% of users |
| Invites sent per referrer | >3 |
| Invite acceptance rate | >15% |
| Referred user retention | >40% D7 |
| **Viral Coefficient** | 0.4-0.6 |

### Loop 3: Companion Discovery Loop

```
Creator makes public companion
        ↓
Companion appears in discovery
        ↓
New user tries companion
        ↓
User creates their own companion
        ↓
User becomes creator
        ↓
[Loop repeats]
```

**Key Metrics:**
| Metric | Target |
|--------|--------|
| Public companions | >1,000 |
| Discovery usage | >30% of signups |
| Try → Create conversion | >50% |
| Creator conversion | >5% |

## Viral Mechanics

### Viral Coefficient Calculation

```
K = i × c
Where:
- K = Viral coefficient
- i = Invites per user
- c = Conversion rate of invites
```

**Current State:**
- i = 2 invites per user
- c = 15% conversion
- K = 0.3

**Target State:**
- i = 4 invites per user
- c = 20% conversion
- K = 0.8

### Viral Coefficient by Feature

| Feature | Invites (i) | Conversion (c) | K |
|---------|-------------|----------------|---|
| Referral program | 3 | 15% | 0.45 |
| Social sharing | 2 | 5% | 0.10 |
| Public companions | 1 | 10% | 0.10 |
| **Combined** | - | - | **0.65** |

## Key Takeaways

1. **North Star = WAC** - Weekly Active Conversations drives all decisions
2. **Retention over acquisition** - D7 and D30 are critical health indicators
3. **Viral coefficient matters** - Target 0.5+ for sustainable growth
4. **Cohort everything** - Compare cohorts, not aggregates
5. **Lead metrics predict** - Session frequency predicts retention and revenue
6. **Alert early** - Red/yellow thresholds catch problems fast
